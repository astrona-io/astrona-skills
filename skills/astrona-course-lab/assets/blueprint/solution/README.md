# Reference solution — {{path_id}}

Put the finished, correct end state here: the manifests / files a learner
produces if they solve the lab perfectly. `astrona test` applies this folder
(`testing.manifests` in `config.yaml`) and then runs grading against it, so
this is what proves the lab's own grading passes.

Learners never see this folder during `astrona run` / `astrona submit`.
